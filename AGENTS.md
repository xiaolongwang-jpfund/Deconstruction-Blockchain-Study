# Deconstruction Blockchain Study

## Purpose

This repository records a long-running reading and hands-on study of *Deconstruction of Blockchain* (ISBN 978-7-302-52058-0), Bitcoin fundamentals, distributed systems, cryptography, and blockchain engineering.

## Working rules

- Write study notes in Chinese; keep code, filenames, identifiers, and commit messages in English.
- Do not copy the book in full or publish substantial copyrighted passages. Record summaries, questions, short quotations, and page references instead.
- Every practical exercise must state its learning objective, assumptions, how to run it, and what was observed.
- Treat all blockchain code as educational until it has tests, threat modeling, review, and security auditing.
- Never put passwords, private keys, seed phrases, API tokens, personal identity documents, or real funds in this repository.
- Use local-only keys and test networks for experiments. Never connect an unfinished implementation to a public network.
- Add a dated entry to `logs/daily/` after each study session and update the relevant roadmap or notes.
- Before publishing or pushing, run the checks described in `docs/public-release-checklist.md`.

## Repository map

- `reading/`: reading plan, chapter notes, questions, and glossary.
- `labs/`: small experiments and the educational blockchain implementation.
- `docs/`: architecture, decisions, threat models, and release checklists.
- `logs/daily/`: dated learning records.
- `references/`: links and bibliographic information, not copied book content.

## Definition of done for a study session

1. The concept is explained in my own words.
2. At least one question or assumption is recorded.
3. A runnable experiment, diagram, or worked example is added when appropriate.
4. The daily log links to the files changed.
