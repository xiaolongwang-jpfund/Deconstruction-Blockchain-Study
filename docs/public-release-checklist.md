# Public release checklist

在 GitHub 公开仓库前逐项确认：

- [ ] 没有 passwords、private keys、seed phrases、API tokens 或真实钱包数据。
- [ ] 没有身份证件、私人地址、私人邮件或其他不应公开的个人资料。
- [ ] 没有复制书籍全文或实质性长段落；笔记均为自己的总结并保留页码引用。
- [ ] 所有示例使用本地假数据或 testnet，不使用真实资金。
- [ ] `git diff --check` 通过。
- [ ] README 能让陌生读者理解项目目的、边界和运行方式。
- [ ] 代码中的警告、限制和未完成部分已写明。
- [ ] 已确认 GitHub 仓库的可见性、名称和许可证选择。
